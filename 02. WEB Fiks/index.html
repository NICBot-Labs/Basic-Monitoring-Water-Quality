📱 Sistem Monitoring Kualitas Air Kolam Ikan

Versi: 3.0 IoT Edition - Complete with Dashboard Simulation 🐋📊🎮

Dikembangkan untuk: Monitoring otomatis kolam ikan dengan visual underwater, grafik interaktif, dan simulasi sensor real-time

✨ Fitur Baru v3.0:

  • 🎮 Dashboard Simulation Mode - ON/OFF button langsung di dashboard
  • 🎚️ Quick Sliders - Kontrol 4 sensor dengan 4 mini slider
  • 📊 Real-time Preview - Lihat perubahan data saat menggeser slider
  • 🔄 Seamless Integration - Simulasi terintegrasi sempurna dengan data real monitoring

🔧 Komponen Hardware:

  • ESP32 - Microcontroller utama dengan WiFi
  • ATmega328 - Slave controller untuk sensor
  • Module Ethernet - Komunikasi data stabil
  • Sensor Temperature - DS18B20
  • Sensor pH - pH Probe dengan modul analog
  • Sensor Turbidity - Turbidity sensor analog
  • Sensor TDS - TDS probe analog

📊 Fitur Utama:

  • ✅ Monitoring Real-time 4 parameter air
  • ✅ Dashboard responsif dengan efek animasi underwater
  • ✅ Grafik real-time setiap sensor (Chart.js)
  • ✅ Sistem alert otomatis abnormal
  • ✅ 🎮 Dashboard Simulation Mode - Kontrol manual sensor dari dashboard
  • ✅ Export data CSV, JSON, Excel, PDF
  • ✅ Analytics & statistik data dengan grafik
  • ✅ History database unlimited
  • ✅ Visual ikan berenang & seaweed 🐠
  • ✅ Paus raksasa berenang di background 🐋
